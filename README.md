# 「顧客継続力」3分診断シート（10問版）

## 目的
5問版との比較用。5つの経営指標を各2問、合計10問で診断します。

## 採点
- できている：4点
- ある程度できている：3点
- あまりできていない：1点
- できていない：0点

40点満点
- 0〜10：売り切り型
- 11〜20：フォロー型
- 21〜30：伴走型
- 31〜40：顧問型

## 5つの経営指標
各2問の合計、8点満点
- 継続設計力
- 顧客理解力
- 価値拡張力
- 関係拡張力
- 顧問ポジション力

## GitHub Pages公開
5問版とは別リポジトリ推奨：
`customer-retention-diagnosis-10`

1. 新しいPublicリポジトリを作成
2. このZIP内のファイルをすべてアップロード
3. Settings → Pages
4. Deploy from a branch
5. main / (root)
6. Save
